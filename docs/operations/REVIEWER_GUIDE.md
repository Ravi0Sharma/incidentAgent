# Reviewer Guide

Approve only a hypothesis that names evidence, a causal mechanism, uncertainty,
and safe next checks. Treat confidence as a ranking, not proof. Reject when
there are contradictions, missing sources, weak citations, or a stale review
revision. Reload after `409 stale_incident_revision`; another event or reviewer
has updated the incident. Feedback should identify the unsupported claim or
missing evidence. Approval creates a local draft only in the POC.
